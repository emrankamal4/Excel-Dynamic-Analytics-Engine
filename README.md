# Excel Dynamic Analytics Engine

An Excel analytics project built around **Dynamic Array functions** to automate filtering, sorting, ranking, KPI analysis, and data-quality monitoring.

The goal was to move beyond static Excel analysis and build outputs that **automatically update when the source data changes**.

## 📊 What This Project Includes

### KPI & Performance Analysis

* Total Revenue
* Total Profit
* Total Orders
* Average Order Value
* Profit Margin
* Top Product
* Top Region
* Top Salesperson

### 🔎 Dynamic Analysis

* Dynamic Product, Region, and Salesperson lists
* Revenue-based ranking
* Dynamic sorting and filtering
* Top-N analysis

### 🛡️ Data Quality Monitor

Identifies:

* Zero-quantity orders
* Discounts above 20%
* Suspicious transactions
* Issue counts by type

## 🧠 Dynamic Array Functions

The project focuses on eight important functions:

| Function     | Use                              |
| ------------ | -------------------------------- |
| `FILTER`     | Find specific records and issues |
| `UNIQUE`     | Create dynamic lists             |
| `SORT`       | Sort dynamic results             |
| `SORTBY`     | Sort by another column           |
| `SEQUENCE`   | Generate rankings                |
| `TAKE`       | Extract Top-N results            |
| `DROP`       | Remove unwanted data             |
| `CHOOSECOLS` | Create focused output tables     |

## 🛠️ Tools

**Microsoft Excel • Excel Tables • Dynamic Arrays • SUMIF • COUNTIF • INDEX/MATCH**

## 💡 Key Learning

This project showed how Dynamic Array functions can work together to create **automated, reusable analysis** without manually maintaining ranges.

## 📁 Workbook Structure
